# Entries

This folder is the journal’s content.

| File | What it is |
|---|---|
| `index.json` | Catalog the home page, search, and topics read |
| `{id}.json` | Full text of one entry |
| `log.json` | Chronological publish log |
| `images/` | Photos uploaded from `/studio/` |

Do not edit these by hand unless you want to. The owner studio writes them when you publish.
